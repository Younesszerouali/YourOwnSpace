YOUR OWNSPACE — PLAYLIST BUILD

Open index.html through GitHub Pages after uploading all files and the music/ folder.
The nine included MP3s are bundled and playable in the site. Keep the music folder beside index.html.
Additional files selected with Add Song are temporary in that browser session. To share new uploads between devices, connect a storage backend such as Supabase Storage and configure its access policies.
The bundled files are not automatically synced to Raouaa's device by GitHub Pages. Only upload audio you have permission to distribute.

Files: index.html, style (2).css, script (3).js, music/*.mp3, SUPABASE_SETUP.sql
